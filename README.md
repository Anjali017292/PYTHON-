# 📊 Retail Sales Dashboard (Excel Project)

## 📌 Project Overview

This project is a **Retail Sales Dashboard** created using **Microsoft Excel / Google Sheets**.
It analyzes sales data and presents key business insights using **Pivot Tables, Charts, and KPI Cards**.

---

## 🎯 Objective

The goal of this project is to transform raw sales data into a **visual dashboard** that helps in:

* Understanding sales performance
* Identifying top products and regions
* Analyzing profit and revenue trends

---

## 📁 Dataset Details

* 📊 Total Records: **15,000+ rows**
* 🧾 Data includes:

  * Order ID
  * Date
  * Product
  * Category
  * Sales
  * Profit
  * State
  * Region
  * Payment Mode

---

## 📊 Features of Dashboard

* ✔ Total Sales KPI

* ✔ Total Profit KPI

* ✔ Total Orders

* ✔ Average Order Value

* 📈 Monthly Sales Trend

* 🥧 Category-wise Profit Distribution

* 📊 Top 10 Products by Sales

* 🌍 State-wise Sales Analysis

* 💳 Payment Mode Distribution

* 📍 Region-wise Profit

---

## 🛠 Tools Used
